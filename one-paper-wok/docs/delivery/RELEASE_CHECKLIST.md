# P9 客户交付清单（草案）

## 阻断（任一未消除则不给客户）

- [ ] 约定范围内无阻塞缺陷
- [ ] 已存资料可经备份恢复
- [ ] 无数据丢失路径
- [ ] 无隐私越权（私人笔记默认不上传）
- [ ] 无计费失控（无网/无额度仍可阅读笔记导出）
- [ ] 签名 APK 与包名归属确认
- [ ] 已知限制清单随包分发

## 本轮已具备

- [x] 可组装的 debug 工程（`android-app/`）
- [x] 本地优先、无登录主路径
- [x] 回煲审阅与合并单测
- [x] 备份格式不含 token
- [x] 食堂入口已删除
- [x] 使用/运维说明见 `android-app/README.md` 与本目录文档

## 本轮不做

- 生产签名与商店上架
- 采购 PSPDFKit
- 部署新后端或购买模型
- 开放食堂

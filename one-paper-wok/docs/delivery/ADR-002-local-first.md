# ADR-002 本地优先，后端只做可选云能力

- 状态：Accepted
- 日期：2026-09-05

## 决策

- 个人书房权威副本在设备：Room + 私有文件目录。二进制不进 SQLite。
- 无登录可导入、阅读、笔记、导出、备份恢复。
- 后端（若部署）只做 AI、可选重型 OCR、额度。首版不做全量同步。
- 客户端只连自有后端。SSE 只走 OkHttp/Retrofit 这一套 HTTP。
- 试点 Worker：PostgreSQL `SKIP LOCKED` 单 Worker，不上 Celery+Redis。
- 换机恢复 = 用户先完整备份再恢复。这不是同步协议。

## 上传红线

- 用户允许且有额度时，才上传当前提问的检索片段或指定页图、任务元数据、用量。
- 不默认上传全书或私人笔记。
- 日志不落正文与 token。
- 保留期与删除 API 必须可执行（云能力启用后）。

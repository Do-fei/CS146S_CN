# Design Spec（方向，非终稿）

## 导航

书架 / 一纸 / 食堂 / 我的。扫描是书架主新增。食堂本版是预告 + 分享，不是信息流。

## 色彩 token

| Token | 值 | 用途 |
|---|---|---|
| `paper` | `#FAF7F1` | 页面底 |
| `clay` | `#BD593B` | 主操作 |
| `ink` | `#302D29` | 正文 |
| `mist` | `#E8E2D6` | 分割/芯片 |

| `ai` | `#6A5B8A` | AI 层 |
| `user` | `#BD593B` | 用户层 |

## 必须覆盖而预告片没有的状态

首次引导；DRM/损坏确认；连拍质量；页面整理；任务 killed / waiting_for_network；选区；AI 历史；手写校对；回煲冲突；导出范围；备份冲突；额度用尽；无网；拒相机；大字体；空态。

触控目标 ≥ 48dp。遵守系统返回与 edge-to-edge。

# 首版范围（方案 v0.1）

## Core（本轮工程必须有可运行切片）

| 能力 | 本轮切片 |
|---|---|
| 导入与自炊台 | SAF 导入 EPUB/PDF/图片/文本；复制到私有目录；全书 vs 摘录状态分离；DRM 加密文件拒绝绕过 |
| 书架 | 封面元数据、搜索、一书一档案、删除影响说明；不按书名合并 |
| 阅读器 | 文本/EPUB 抽出重排阅读 + 字号；PDF 用系统 `PdfRenderer` 固定版式预览（选择/搜索见 P1 门禁） |
| AI 搭子 | 分书会话、Fake Provider、范围条、证据不足声明；只导入一章不生成全书结论 |
| 笔记本 | 摘录/文本/图片；识别稿与用户稿分列 |
| 一纸项目 | 稳定 sectionId；指定段可编辑；再生成不覆盖用户稿 |
| 回煲 | ChangeProposal 逐条决定 + 三路合并夹具 |
| 导出备份 | Markdown 导出、JSON 完整备份恢复、token 不进包 |
| 设置 | 主题、上传偏好、存储、关于；无食堂入口 |

## Conditional（未书面划进首版）

- 一纸食堂：不做，不留空入口。
- 云端重型 OCR：仅接口，默认关。
- 扫描生成 EPUB：只出评估备忘，不写客户承诺。
- 账号：不做。

iOS/桌面/Web、开放社区、推荐、私信、排行、交易、KMP、BYOK 并行、跨设备实时同步、自动翻页检测拍摄。

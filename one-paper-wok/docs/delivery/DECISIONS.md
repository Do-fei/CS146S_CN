# 一纸书煲 · 首批决策（方案 v0.1 · 已采纳）

锁定日期：2026-09-05。  
依据：讨论稿 v0.1 第 11 节推荐默认值。实施授权将「Implement the plan」视为书面批准方案 **v0.1**，并按推荐默认执行。

本文件是交付版范围与安全模型的权威记录。变更须新增 ADR，不得静默改默认。

## D1. 客户、设备、渠道

**决定：** 试点 5–20 人受邀侧载。真机门禁先定 1 台低配国产无 GMS + 1 台主流机。

**不选的后果：** P1/P9 无法做真机门禁，minSdk 与包体会漂。

**本轮落地：** `minSdk = 26`。无目标真机时，P1 先跑 JVM 夹具与模拟器冒烟；真机项记为门禁未关，不把模拟器结果冒充真机。

## D2. 人员与时间

**决定：** 按 1 名资深 Android + 0.5 后端规划；Core（P1–P7+P9）约 22–38 人周。先做 P1，再按阶段推进工程。

**不可砍：** 阅读定位、回煲逐条审阅。日历不够只能砍食堂或降低扫描/手写承诺。

**本轮落地：** 完成 P0 文档、P1 JVM 夹具、P2–P7 可安装本地优先骨架；P8 食堂不做；P9 交付清单与已知限制。

## D3. AI / OCR 与上传

**决定（2026-09-05 讨论修订，见 ADR-004）：**

- 印刷体默认端侧 ML Kit **bundled** 中文。DeepSeek **不当全书 OCR**。
- 产品不提供 AI 服务。用户在设置里填写自己的 DeepSeek Key（BYOK）。不填走 Fake。
- Key 只存在本机密钥库，不进 APK、不进备份、不进日志。
- 提问时只发送当前选区/检索片段到 DeepSeek；私人笔记默认不发送；不默认上传全书。
- 真机：Pixel 7 + OPPO 小折叠第一代（机不在身边时只用模拟器，不冒充真机）。

**本轮落地：** `RoutingAiProvider` + `DeepSeekClient`（`deepseek-v4-flash`）+ Fake；ML Kit 印刷 OCR。

## D4. 账号与同步

**决定：** 首版无登录、无实时同步。导入、阅读、笔记、导出、备份全部本地可完成。换机 = 完整备份再恢复。

**本轮落地：** 无强制登录页。卸载前提示未备份。token 不进备份。

## D5. 食堂

**决定（2026-09-05 讨论修订，见 ADR-005）：** 底栏四项：书架 / 一纸 / 食堂 / 我的。本版食堂是预告页 + 系统分享/导出，不是社区。禁止假动态。真正的发布/互动留下一版，并须同时批运营与管理端。

## D6. 品牌与视觉

**决定：** 交付名 **一纸书煲 / OnePaper**。旧仓库「一纸读书煲 / One Paper Wok」仅历史原型。

视觉方向（非终稿）：暖纸白 `#FAF7F1`、陶土橙 `#BD593B`、深炭 `#302D29`。预告片与 Flutter UI 不批准为终稿。

**本轮落地：** 包名锁定 `com.onepaper.app`。正式签名由你本机 keystore 保管。反馈邮箱：`nuannuan.dean@gmail.com`。分发：5–20 人受邀侧载。

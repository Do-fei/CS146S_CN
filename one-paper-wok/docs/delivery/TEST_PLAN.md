# 测试计划

## 层次

1. 单测：Locator 稳定、回煲三路合并、任务幂等、中文 n-gram、OCR 框映射。
2. Room 迁移与备份完整性（本轮：备份 JSON 往返）。
3. UI 旅程：空态、无网、拒权、大字体（本轮：Compose 可导航切片）。
4. 真机：至少低配无 GMS + 主流。模拟器不得冒充真机。
5. AI/OCR：固定授权样本 + 人工参考。禁止「有输出即通过」。

## 九条必测流程（提示词第 10 节）

1. 导入 EPUB → 离线阅读 → 改字号后批注仍回到原文。
2. 文字 PDF 阅读/搜索/跳转（P1 门禁；失败则走图片 PDF + OCR 层）。
3. 拍摄/导入书页 → 页级 OCR → 校对 → 全书 vs 摘录状态不撒谎。
4. 只导入一章时 AI 不得输出全书结论；引用可点回。
5. 一纸分节编辑后，再生成不覆盖用户稿。
6. 回煲逐条接受/拒绝；计算期间用户又改 → 冲突回审阅。
7. 无账号导出与备份恢复；token 不在包内。
8. 额度/超时/取消路径可读，阅读与笔记仍可用。
9. 食堂（未入选，本轮标记 N/A）。

## 基线实验（讨论值，非客户承诺）

200 页扫描书、50MB EPUB、单页 4000px 长边；冷启动、首屏、翻页掉帧、峰值内存；单页印刷 OCR、AI 首 token。

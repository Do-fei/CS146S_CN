# 狐尾 × 远瞳 · 起点双顶流融合规范

**适用**：688 万字全书（50 章），在既有悬疑主线与同桌关系不变的前提下，综合两位写手的叙事技法。

## 两位写手各自带来什么

| 维度 | 狐尾的笔（《神秘复苏》系） | 远瞳（《异常生物见闻录》《希灵》系） |
| --- | --- | --- |
| 恐怖 | 规则先于情绪；违反必有代价；冷、硬、可验证 | 宏大设定落地日常；怪诞里藏温情 |
| 叙事 | 短句断拍；禁止自作聪明；文档/报告体穿插 | 吐槽式旁白；角色嘴硬心软；信息用对话抖出来 |
| 人物 | 主角压情绪、记规则、少废话 | 配角有鲜明口癖；严肃场合一句歪楼 |
| 世界观 | 「不能 xxx」比「好可怕」重要 |  bureaucracy 式超自然机构（编目、收费、表格） |

## 本书怎么融（不抄设定，只借技法）

### 狐尾层 · 规则恐怖

1. **馆规/停止键/十一点** 写成可背诵的条目，带编号与后果，例如：
   - 「播放键：听完整盘，她在第四层，你在合影里让座——不是比喻，是位置变更。」
   - 「违反第二条（十一点后应广播）的人，点名册上会少一行，保安仍正常查考勤。」
2. **惊悚单元** 先给现象，再给规则，最后给代价；禁止纯形容词吓人。
3. **大韦（你）** 遇险时少抒情，多记：时间、位置、键温、糖还剩几颗。
4. **警察/编目簿** 偶尔露出报告体一行，像事故记录，不解释完。

### 远瞳层 · 冷幽默与世界观

1. **吐槽只给读者看一半**：大韦内心可以一句「这破馆收费比电信还细」，嘴上仍按规则走。
2. **老周、阿青、小海** 各有口癖：
   - 老周：把灵异说成路况/计价器问题；
   - 阿青：短信像客服，句号很少；
   - 小海：工牌、检修、「别数发光的群」。
3. **编目簿/倒带馆** 写出荒诞行政感：括弧空白、待定、编目费——像异闻录里填表，但**不**抄异常局设定。
4. **北京日常** 当锚点：豆浆结皮、二环车流、校医创可贴——怪事贴在这些细节上才像远瞳。

### 融合句型（示例，禁止整段复制当模板）

```
狐尾：「停止键比播放键凉。凉，说明它最近被按过多——按多了，会漏。」
远瞳：「阿青说编目费按分钟计，我一度怀疑她兼职电信客服，直到看见她拿秒表。」
融合：「馆规第四条你背熟了：甜的东西要沉。赵宜把糖塞给你时说这是废话——后来才明白，废话和规条有时是同一句。」
```

## 与同桌线的关系

- **二层甜度保留**：袖口、怕黑、两杯豆浆、两个解；无告白。
- **狐尾不杀温情，只杀滥情**：恐怖段落里不写「心里一暖」；温情放在白天、豆浆、值日。
- **远瞳不毁悬**：笑话不揭底，不提前说破十一点是什么。

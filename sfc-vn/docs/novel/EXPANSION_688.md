# 688 万字扩写 · 总纲

**目标：6,880,000 字**（在 488 万基础上净增约 198 万）

## 策略

- **50 章 × ~137,600 字** ≈ 688 万
- 保留现有 488 万正本 prose，每章 **+~39,500 字** 独特场景（非循环、无编号后缀）
- 不新增章节号，深化既有 50 章

## 每章必增内容

| 类型 | 要求 |
| --- | --- |
| 新惊悚单元 | 1 个完整事件，可查细节收尾 |
| 线索 | 推进悬疑表之一 |
| 反转 | 半章内可验证 → 推翻一半 |
| 关系 | 二层甜度或家庭线 1 场 |
| 路线互证 | 每 3 章交叉引用小海/老周/阿青/档案线 |

## 严禁

`第N次` / 编号后缀（`收束·4900` / `好友·123` / `（八月·100）`）/ `压进数学书` / `B面转半圈` / 模板堆叠

# 《十一点的城市》小说版

由游戏设定与剧本扩写的长篇小说。第二人称「你」，同桌视角。文风按 `story-deslop`：口语、具体动作、少讲义腔。

| 卷 | 章节 | 内容 |

| 序 | 00 | 十一点从哪来 |

| 卷二　倒带馆 | 09–15 | 西单 → 食街 → 三楼 → 磁带 → 停止键 |

## 与游戏差异

- 允许内心独白、环境延展、同桌二层青涩（在意、不说破，无告白）
- 规则只在自然语境出现，不轮流念须知
- 四个名字：赵宜、阿青、老周、小海；其余用身份
- 磁带仍断在「我选——」，不写「我选你」

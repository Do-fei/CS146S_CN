# 《十一点的城市》小说版

由游戏设定与剧本扩写的长篇小说。第二人称「你」，同桌视角。文风按 `story-deslop`：口语、具体动作、少讲义腔。

## 结构

| 卷 | 章节 | 内容 | 目标字数 |
| --- | --- | --- | --- |
| 序 | 00 | 十一点从哪来 | 0.8万 |
| 卷一　同桌 | 01–05 | 失踪前三天 | 2万 |
| 卷二　小路 | 06–15 | 第三夜至倒带馆 | 4.2万 |
| 卷三　漏句 | 16–18 | 停止键与黎明（主结局） | 1.2万 |
| 卷四　八个早晨 | 19–23 | 其余结局的侧写片段 | 1.5万 |

**全书目标：约 10 万字。**

主叙事走「倒带馆 / 漏句」线；卷四以短篇片段呈现另外八个收场，不写成游戏攻略。

## 与游戏差异

- 允许内心独白、环境延展、同桌二层青涩（在意、不说破，无告白）
- 规则只在自然语境出现一次，不轮流念须知
- 四个名字：赵宜、阿青、老周、小海；其余用身份

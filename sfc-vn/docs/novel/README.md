# 《十一点的城市》小说版

由游戏设定与剧本扩写的长篇小说。第二人称「你」，主人公**大韦**（赵宜同桌）。文风按 `story-deslop`：口语、具体动作、少讲义腔。

## 结构

| 卷 | 章节 | 内容 |
| --- | --- | --- |
| 序 | 00 | 大韦与十一点 |
| 卷一　同桌 | 01–08 | 失踪前三天 → 第三夜 → 天桥选路 |
| 卷二　倒带馆 | 09–15 | 西单 → 食街 → 磁带 → 停止键 |
| 卷三　漏句 | 16–18 | 爬回 → 小的路 → 主结局 |
| 卷四　八个早晨 | 19–23 | 其余结局的侧写片段 |

**全书约 48.5 万字**（统计：`python3 tools/count_novel.py`）

## 大韦怎么出现

- 序章点明：海报里叫大韦，正文仍用「你」
- 爸、班主任、警察、赵宜妈妈 → **大韦**
- 赵宜日常喊**同桌**，急了偶尔**大韦**（每章不超过 2 次）

- 四个名字：赵宜、阿青、老周、小海
- 磁带仍断在「我选——」

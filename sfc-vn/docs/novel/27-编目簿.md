# 第二十七章　编目簿

试听间里，卡座吐出的带还在柜台边发热。标签空白，壳烫，像刚从谁喉咙里掏出来。你还没按停止。手指悬在键上方，悬了多久，你自己也不清楚，馆里的钟不帮你数。

阿青从后仓出来，手里一本硬壳登记簿，封面没有字，只有一道浅压痕，像被人反复按过停止键。她把簿子放在柜台玻璃上，玻璃下压着宝丽来，赵宜春游那张，眼睛淡过一圈，你移开视线。

「编目。」阿青说，「按停止之前，你要看一眼簿。」

你说：「我没写名。」

「写了。」她把簿子推过来，「馆记名，不靠笔。靠你站在这里，手悬在停止键上，还没退。」

你低头。簿子翻开，最新一页，铅笔字，淡，像会蹭掉：

赵宜（未完成）
大韦（待定）

待定后面括弧，括弧里空白。空白不是没写，是还没收。你喉咙发紧：「我什么时候……」

「从发送失败那分钟。」阿青用伞骨点簿角，「23:17 空档，电信话单对不上馆钟，空出来的那一格，馆拿来登记。不是抓你，是留座。留座要收费，收费不是钱。」

你问：「什么收费？」

阿青没答，把页翻过去。上一页是别人，姓被涂黑，只剩状态：已播放。再上一页：已交出。再上一页：赵宜（试听）。你看见她的名在「未完成」之前，还出现过「试听」，像一个人被馆分阶段写进簿里。

「编目簿的规矩。」阿青说，「名字写进簿，喇叭就不会乱用你的嗓子。不写，馆会代写。代写，你就不是待定，是条目。」

你抓紧袖口：「条目是什么？」

「条目是会被播完的人。」她说，「播完，照片冲好了，人就薄。薄了，摸不到。」

钟还是二十二点五十九。秒针抖。你没看六十。你只看簿上那行字：大韦（待定）。待定，像方程里第三个根，前两个是赵宜的两个解，第三个是你还没选的那条路。

「我能划掉吗。」

阿青摇头：「划掉，等于按播放。播放，她完整，你薄。待定是停止键给的位子。按停止，待定可能变成漏句同行。不按，待定可能变成条目。」

她把笔推过来。笔杆凉，和停止键同温。笔帽上贴着极小一张标签：编目费·一颗糖。

你摸口袋。三颗变两颗，你不知道哪一颗是编目费预扣的。阿青说：「别数。数过了，会减路灯。」

「编目费到底是什么。」

「是你还当人的证据。」阿青把簿合上，「糖、指纹、分钟，三选一。大多数人选分钟，因为分钟最像没损失。分钟最像大路。大路说：你没丢东西，只是睡过头。」

你想起 23:17。你当时应该睡了。或者说，你以为自己睡了。那个分钟空着，现在落在簿上，落在你名后面，待定。

赵宜在带里又咳，极轻：「同桌，别写全名。写全名，馆会认账。」

你没应。应名交换。交换大路。你不应。

阿青把簿又翻开，指「大韦（待定）」下面一行小字，小字是馆自动印的，印得很浅：

编目成本：同步半拍 / 或 糖一颗 / 或 指纹一纹

三行，像三个解。你选一个，她选另一个。第三个留给停止键。

「半拍同步是什么意思。」

「你走路，镜里你慢半拍。慢半拍，馆好学你。学你，四楼就多一个你。多一个你，按停止的时候，就有两个手指。一个按停止，一个按播放。馆爱完整。完整好编目。」

你后背发凉。三楼模特的塑料手指指向你们，你绕开，没看。

「所以编目簿不是登记找到了谁。」你说，「是登记谁会被听完。」

「找到了，也要登记。」阿青把耳机灯转青绿，「找是路，登记是岸。岸上的人，才配按停止。按停止，不是结束，是留缝。缝窄，窄到只够漏句爬回。」

她把簿最后一页给你看。页底，极小一行：

停止键同时钉住两人

你手指还在停止键上方。键凉。凉像她冬天塞给你暖手的糖纸。带里赵宜说：我选——，还是断在那里。

名字不是 twist，在成本：你以为编目是赵宜一条，簿上早有两行。停止键按下去，不是只改她，也改你。改法写在括弧里，还没填。

这一章，只到你看完簿。按，在下一章。

第566遍翻簿。食街方向飘来豆浆味，淡，像省略号。赵宜在带里说仍没寄回家那句，不是给你听的，给妈妈的。编目簿有没有妈妈的名？阿青说妈妈的名在大路，大路写等，等不等于条目，等是岸上的编目，不要糖。

第567遍翻簿。四楼极轻一声咳嗽，像赵宜，像又不像。阿青说馆会学，学声音，学口型，学欢迎光临，别应。簿上小字：停止键同时钉住两人。你手指仍悬在停止键上方，键凉，像同步半拍还没扣完。

第568遍翻簿。赵宜（试听）箭头赵宜（未完成），馆写的，写得很直，像大路。你问未完成之前是什么，阿青说失踪，失踪写不进簿，失踪是大路，大路写寻人启事，启事照片亮，簿上照片淡，亮和淡是同一个人两个状态。

第570遍翻簿。监控屏跳一帧，白天第三排靠窗，赵宜转笔，笔掉，踩你脚。阿青说别指，指它以为你认账。你收回手。带里赵宜咳一声：同桌，别写全名，写全名馆会认账。你没应，应名交换，交换大路。

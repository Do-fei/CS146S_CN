# 第二十八章　薄了

停止键按下去那一下，馆里所有声音退后一步。退一步，像给缝让路。疼从指尖进，进袖口，进牙关。你咬紧，没叫。叫出来，像应广播。

磁带嘶嘶声断。断得很干脆。卡座吐带，像吐骨头。带热，热得烫指。阿青捡，放柜台，标签仍空白。她说：等。等缝。缝很窄。

你听见带里极轻一声，半个音节，像「我选」后面被吞掉的那截。吞掉，不是消失。是漏到别处。别处可能是第三排靠窗。可能是你袖口。可能是停止键和播放键之间的缝。

然后，监控屏跳了一帧。

不是第三排靠窗。不是赵宜转笔。是你。春游那张合影，你站在靠窗外侧，手指比 V，笑成一条线。一帧里，你右食指的螺纹浅了，浅像被橡皮擦过，擦到几乎平。下一帧，又回来。回来，但不完全。不完全，像长回来一点，长不全。

你盯着屏幕。阿青没看。她说：「别指。指它以为你认账。」

「那是什么。」

「薄了。」她说，「一帧。一帧够馆记账。记账，不是删你。是试扣编目费。」

你摸右食指。纹理还在。在，但心里那一帧还在跳。跳，像发送失败和发送成功之间差的那一格。

「编目簿写的指纹一纹，是这个？」

「三选一。」阿青说，「你站待定，馆自动试扣。试扣成功，就不扣糖。试扣不成功，扣糖。再不成功，扣分钟。」

「成功了吗。」

「成功一帧。」她说，「一帧，够薄一毫米。一毫米，白天摸不到。夜里，合影里你淡一点。淡一点，赵宜爬回时，才不会把你当完整的人挡路。」

你喉咙发紧。完整的人，摸不到被听完的人。现在，你也可能被摸不到。

「她会看见吗。」

「看见一帧，就会怕。」阿青说，「怕，说明还当人。当人，抓袖口。不抓条目。」

扶梯方向有脚步声。鞋跟敲瓷砖，错半拍。错半拍像漏句。像从停止键里爬出来。你往三楼跑。监控屏上，你的指纹又跳浅一帧，这次左手中指。你把手藏进袖口。藏，像藏证据。

赵宜湿透了，黄风衣贴在肩上，齐刘海滴着水。她在笑，笑得不完整，像画面少了一帧。她说：「我从停止的地方爬出来。」

你喊赵，停住。警察说过，先别喊名字。你改成：「你……我头有点疼。」

不是谎。疼是真的。停止键的疼，和一帧变薄的疼，叠在一起。

她抓住你的袖口。褶是真实的。你感觉得到。你问：「你看见了吗。」

「看见什么。」

「照片。我。」

她停半拍。停半拍里，你数呼吸，数到四停。四之后，她接：「看见一帧。一帧里，你薄了。薄了，我还抓得到袖口吗。」

「抓。」你说，「抓到了，就不算播放。」

她攥紧。指节发白。白，像照片冲淡了那一圈。

阿青在四楼喊：「别在三楼停太久。三楼会学。」

你挡在赵宜和镜之间。镜里你的影子慢半拍。慢半拍，像编目簿写的同步半拍。半拍，是成本。成本已付。付完，你待定变同行。

监控屏黑了一秒，又亮。亮时，合影里你的位置，淡过一圈。赵宜的位置，也淡过一圈。两圈，像两个解，各淡各的，草稿纸上还能碰面。

「停止键同时钉住两人。」你说。

「嗯。」阿青说，「钉住，不是钉死。是留缝。缝里，两个人都薄一毫米。薄一毫米，才爬得回。」

你想起她说过：完整了，你就薄。薄了，就摸不到。现在，你按的是停止。停止，也薄。薄，是爬回的路费。

「一帧够吗。」

「够当同桌。」赵宜说。她第一次说这句话。现在，你只知道，一帧的薄，换她站在扶梯口，湿，笑得不完整，抓你的袖口。

你把手指藏进她抓着的袖口里。藏，像把指纹藏起来。藏起来，下一帧也许就不浅。

「走吧。」阿青说，「食街。别坐。坐了会点播。」

你们往下走。走过监控屏时，你余光又扫一帧。帧里，你的 V 字手势还在，食指纹理浅了。浅，像被停止键蹭过。蹭过，还会长回来一点。长不全。长不全，够当同桌。

这一章，写薄。不写没。没，是大路。大路写结案。

# 第六章　胡同深

灯灭到第七盏，你进胡同了。

身前还有路。路窄，窄到砖缝渗水，往前流。砖缝咬鞋。你改走砖面。走砖面，像听赵宜的。她说过：雨天别走砖缝，缝会咬鞋。咬鞋，像咬名字。名字被咬掉，就不算失踪，算从未被登记。

胡同墙根，半张课表还在泥里。第三排靠窗，名字被泥盖住。你不擦。擦了，像替大路擦证据。证据留着，像暗号。暗号就是我还活着。你当时笑。现在不笑。

收音机没拧紧，女声反复念：崇文，宣武。两个已经被拆进更大名字里的词。北京换皮肤。旧名字还会响。响，你别应。应了，就会以为自己是旧人。旧人走大路。你走小的。

修鞋铺还亮着暖黄。老师傅抬头，指前面：再往前。别停。停久了，雨会把路名洗掉。你谢了。他摆手：走你的。走你的，像不要回报。回报是大路。

你路过一段，墙上海报被雨晕开。少年宫招新生，电话数字只剩前三位。你停两秒，继续。停太久，雨会把路名洗掉。路名洗掉，人就会走到没有站名的地方。

井盖上反着浅脸。你踩过去，脸笑了一下，散了。下面极轻广播，报一个没有名字的站。你当没听见。听见，就要应。应了，站就会写你名。

巷口倒共享单车，铃铛卡一格，风响一声。你数到四停。四是呼吸断掉的地方。你还不知道。只觉得数多了心乱。笔记没写要数灯。也没写要数铃。你停数。

猫从墙头跳下来，爪印踩进泥。泥里除了课表，还有半张糖纸，橘子色。你捡，纸温，像刚从口袋掉。你放进口袋，和三颗糖分开放。

胡同深处，有人家电视开着。声音被雨压扁，听不清词。你路过，闻到炸酱面酱味，混着潮砖。你想：要是赵宜在，她会说：同桌，我饿了。你说：那去后面。她说：便利店的饭团过期比较甜。你笑：过期还甜。她说：甜的东西要沉。

你当时不懂沉。现在懂一点。懂一点，就够你继续走。

夜市方向，蒸汽还没起来。空摊位像蹲着的人抱膝。塑料棚滴水，节奏和心跳错半拍。你站十秒，等自己对齐。对齐了，再走。走，别回头。回头的人，容易被留到打烊。

空凳上有一顶绿帽。你没碰。碰了，像认领。认领，大路会来收。

有人发传单，纸到你手里变成空白。你攥着，纸温温的，像刚从复印机出来。纸角盖着校徽。校徽像你的学校。像第三排靠窗。像空位。

珠市口方向风更大。风里有护城河的水腥、有夜市的油烟、有远处二环路持续的低鸣。你把外套拉链拉到喉咙。拉链齿咬在一起，像把白天锁在外面。

你想起去年冬天，补习班结束，她怕黑，抓你袖口。你说：我走中间，灯这边。她笑：同桌，你有时候挺会。有时候挺会，不是告白。是位置。

现在灯灭，你一个人。怕黑留给你。留给你，黑就浅一点。浅一点，你还不够懂。你只知道别应广播，别喊名字。

胡同更深处，有一点橙。橙不是路灯的橙。是某家店还亮着。你没追。追，像大路。你按短信走。短信说天桥。你现在，走向那一点橙。

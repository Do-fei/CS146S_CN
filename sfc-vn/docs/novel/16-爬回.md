# 第十六章　爬回

回家的路上，赵宜走在你左边半步。

和去学校一样。只是她比平时安静。安静里偶尔漏出半个音节，像磁带那端有人误触了暂停。她补，补不对，就笑：「都不是。漏掉的那个，其实是怕。」

你问：「怕什么？」

「怕完整。」她说，「完整了，你就薄。薄了，就摸不到。」

你没接话。你想起阿青说的第四层。你没去。你按了停止。

雨小了。路面反光，像许多浅镜子。她黄风衣在风里贴过来，又分开。你没牵她手。牵了，像要确认什么。你只是让她抓袖口。抓袖口是同桌之间的事。

「我大概会忘一些事。」她忽然说，「你要是记得橘子糖，就够把我拼回来。」

你说：「记得方程有两个解。记得豆浆你请。记得别走大路。」

她嗯了一声。嗯完，又漏出半拍空白。空白里，你听见极轻的「欢迎光临」，像她自己皱眉，把这句话咽回去。

「馆里学你。」你说。

「学我，也学你。」她说，「以后少应。」

你们绕开长安街。走南横街小巷。修鞋铺老师傅抬头指：天桥。就两个字。你谢了，他摆手：走你的。

早点铺还亮着，老板打豆浆。蒸汽糊了玻璃。赵宜停半秒：「以前你总请两杯。一杯自己，一杯放我桌角。」你说：「以后还这样。」她摇头：「以后我自己买。买完了，欠你半句。半句比结清安全。」

单元楼声控灯准时。亮，灭，亮。她数台阶，七级停。你说八。她笑。她把额头抵你肩，很短。像怕停太久，会被楼道录成某一句。

「我回来了。」她说，「不完整。但回来了。」

你开门。家里没开灯。开灯，光打在她脸上。她齐刘海还湿，奶奶灰，在灯下很淡。她看摊开的数学书，看窗台上那件不是她的校服：「你还留着？」

「忘了收。」你说。谎话。你记得。你故意不收。

她没戳穿。她坐沙发，坐不整齐，像漏句也漏在姿势里。你把糖从口袋摸出来，只剩两颗。一颗放她手心，一颗留自己。

「甜的要沉。」她说，「沉了，才不会被倒带冲走。」

她剥糖，含住，侧脸鼓一点。像初三，像没失踪之前。

你给她热汤。你说：「阿姨说汤咸了，留着。」她眼睛红了一下，没哭：「咸说明她还在等。」

她问：「你按停止的时候，手抖吗。」你说：「抖。」她说：「抖就好。抖说明你还当我是人。当人，就不该听完整盘。」

数学书摊在茶几上。她翻一页，卡在应用题。不是不会，是漏。漏在「设 x 为」后面。你拿笔，她按住你手腕：「别写全。写全了，像补全。补全了，我就薄。」

你收笔。她画小人，举牌子：两个解。你圈靠窗那个解。她圈另一个。交换。她笑，笑少一帧：「还是两个解。漏的那个，在停止键里。」

黎明前，妈妈敲门。扣子扣对了。看见沙发上的人，没哭出声，只问：「汤还要不要热。」赵宜哑声：「要。」

你把便利贴翻给妈妈看。两层橙色。旧的：今天的数学我不会，晚上天桥见。新的：方程还是有两个解。我们选了漏的那一个。妈妈点头：「漏的那一个，我也认。」

她进厨房。水龙头响。赵宜看着厨房门：「停止键那道缝，很窄。我爬很久。」你问：「疼吗。」她说：「疼。比怕好。怕会把我留在完整里。疼说明我还漏着。」

她靠沙发，闭眼前：「明天去上课。迟到也行。迟到写进点名，比失踪好写。」

你盖薄毯。毯角碰袖口，褶还在。褶像证据。证明她抓过。证明不是倒影。

天快亮。南横街有人收摊，铁勺碰锅，叮。你守夜，没睡。怕睡过去，她再漏回带里。

她呼吸完整。完整里偶尔空半拍。空半拍时，你握袖口。握一下，她就回来。像按停止。停止不是结束。是留缝。缝很窄。窄够了。

手机亮。对话框恢复。别走大路。下面多一行：这次走了小的。你锁屏。天亮了。

六点半，她醒。先看袖口，再看你：「还在？」你说：「在。」她梦见食街，椅子倒扣，吸管点杯壁三下。你说：「梦里的别信。」

她穿你的外套，袖子长，卷两卷。卷完改抓你的袖口：「还是抓你的。褶子深，像证据。」

出门。早市开了。你买两份早点。她咬两口：「豆浆那杯，我欠着。」你说：「欠着就欠着。」

收音机念崇文、宣武。她听两秒：「口型对不上。」你说：「那我们以后只对袖口。」

到校，绕开校门口宽的。发传单的人问找没找到。你没答。她抓你袖口，抓一下，松一下，再抓。

第三排靠窗，她坐下。班主任：「赵宜，作业补交。」她：「好。」讲到一半会空半拍。你书页里夹半张草稿，两个解，旁边写着：你选。

午休，两杯豆浆。吸管点三下：「省略号还在。」回家跟妈妈说，不是跟同桌。你嗯。

数学课，她写一半卡住。你低声补。她耳朵红：「别在课上补太多。」

放学走小的路。天桥上没贴便利贴。她说：「明天再贴。今天先回家。」

单元楼第七级，她停。你说八。她笑。她回赵宜家。你回自己家。两个解各走各的。草稿纸上还能碰面。

夜里她发消息：别走大路。这次走了小的。你回嗯。发送成功。没有红色感叹号。

你想起按停止。键烫，又凉。你怕，还是按了。完整的人摸不到被听完的人。她说想被抓袖口，不想被收藏。

警察值过夜的事，你后来才听说。赵宜妈妈说的，声音很轻：「他们让我等。等也是一种找法。」你没问哪个警察。问，像要走大路。

赵宜家那锅汤，你喝过一口。咸。赵宜说：「我爬回来，第一件事想喝汤。第二件事想抓袖口。第三件事才想数学。数学还是不会。」你说：「不会就不会。」她说：「不会，老师就不会以为我全好了。全好了，像听完。」

你守夜时，窗外某处钟，秒针在二十二点五十九附近抖了一下。你没看表。看表，像要数。你只看她袖口。褶在。人在。

天亮后，你们分头洗漱。约在校门口小的路碰头。她穿校服，齐刘海，像只是请了几天假。她看见你，先看口袋，再看脸：「糖还在？」你说：「还在。」她松口气：「那就好。」

第一节数学课，她站起来解题。粉笔写到因此，停半拍。你低声补半句。她接上，坐下，耳朵尖红。下课她说：「别在课上补太多。」你把那道题抄进本子，故意留空白。空白像停止键后面没收完的音节。

体育课分组，她跑半圈停，喘，说空半拍像被按暂停。你说：「在。」她笑。笑少一帧。少一帧，也是她。

雨天共伞。她没推。你说：「挤一点。」她笑：「你记得。」你说：「记得。」记得不是浪漫。是习惯。习惯是袖口还在。

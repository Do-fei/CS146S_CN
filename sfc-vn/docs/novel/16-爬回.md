# 第十六章　爬回

回家的路上，赵宜走在你左边半步。

和去学校一样。只是她比平时安静。安静里偶尔漏出半个音节，像磁带那端有人误触了暂停。她补，补不对，就笑：「都不是。漏掉的那个，其实是怕。」

你问：「怕什么？」

「怕完整。」她说，「完整了，你就薄。薄了，就摸不到。」

你没接话。你想起阿青说的第四层。你没去。你按了停止。

雨小了。路面反光，像许多浅镜子。她黄风衣在风里贴过来，又分开。你没牵她手。牵了，像要确认什么。你只是让她抓袖口。抓袖口是同桌之间的事。

「我大概会忘一些事。」她忽然说，「你要是记得橘子糖，就够把我拼回来。」

你说：「记得。」

「记得什么？」

「记得方程有两个解。」你说，「记得豆浆你请。记得别走大路。」

她嗯了一声。嗯完，又漏出半拍空白。空白里，你听见极轻的「欢迎光临」，像她自己皱眉，把这句话咽回去。

「馆里学你。」你说。

「学我，也学你。」她说，「以后少应。」

你们绕开长安街方向。绕开宽的路。走南横街那边的小巷。巷口修鞋铺老师傅抬头，指前面：天桥。就两个字。你谢了，他摆手：走你的。

单元楼楼道，声控灯这次很准时。亮，灭，亮。她一边上楼一边数台阶，数到第七级忽然停：「下一句呢？」

你说：「八。」

她笑：「对。八。」

她把额头抵着你的肩，很短的一下。短到你还没反应，她就抬起来了。像怕停太久，会被楼道录成某一句。

「我回来了。」她说，「不完整。但回来了。」

你开门。家里没开灯。你把灯打开，光打在她脸上。她齐刘海还湿，奶奶灰，在灯下很淡。她看房间，看摊开的数学书，看窗台上那件不是她的校服：「你还留着？」

「忘了收。」你说。谎话。你记得。你故意不收。

她没戳穿。她坐沙发，坐得不太整齐，像漏句也漏在姿势里。你把妈妈给的糖从口袋摸出来，只剩两颗了。一颗放她手心，一颗留自己。

「甜的要沉。」她说，「沉了，才不会被倒带冲走。」

她剥糖，含住，侧脸鼓起来一点。像初三，像没失踪之前。

你给她热汤。不是你们家的汤，是想象里赵宜家厨房那锅。你说：「阿姨说汤咸了，留着。」

她眼睛红了一下，没哭：「咸说明她还在等。」

黎明前，有人轻轻敲门。是她妈妈。大衣扣子这次扣对了。她看见沙发上的人，没有哭出声，只问：「汤还要不要热。」

赵宜哑着嗓子：「要。」

你把便利贴翻给妈妈看。两层橙色。一层旧的：今天的数学我不会，晚上天桥见。一层新的，你昨晚写的：方程还是有两个解。我们选了漏的那一个。

妈妈点头：「两个解。漏的那一个，我也认。」

她进厨房。水龙头响。赵宜看着厨房门，说：「我爬回来，爬得慢。停止键那道缝，很窄。」

你问：「疼吗？」

「疼。」她说，「比怕好。怕会把我留在完整里。疼说明我还漏着。」

她靠回沙发，闭眼前最后一句：「明天……去上课。迟到也行。迟到写进点名，比失踪好写。」

你给她盖薄毯。毯子角碰到她袖口，褶还在。褶像证据。证明她抓过。证明不是倒影。

天快亮。窗外雨停了。南横街有人早起收摊，铁勺碰锅，叮。你坐在旁边，没睡。你怕睡过去，她再漏回带里。

她呼吸是完整的。完整里偶尔空半拍。空半拍的时候，你握她的袖口。握一下，她就回来。

像按停止。停止不是结束。是留一条缝。

缝很窄。窄够了。

手机亮了一下。对话框恢复。最后一句仍是：别走大路。下面多一行，你不记得谁发的：这次走了小的。

你锁屏。天亮了。小的路，从这一章开始，变成白天也要走的事。

回家路上，她走在你左边半步。偶尔漏半音节。你补，她不让补太多。

她说：「完整了，你就薄。薄了，就摸不到。」

你按了停止。你没听完整盘。

雨小了。她黄风衣贴过来，又分开。她抓袖口。你不牵手。

「我大概会忘一些事。」她说，「你记得橘子糖，就够把我拼回来。」

你说：「记得方程有两个解。」

单元楼，她数台阶，七级停。你说八。她笑。

她额头抵你肩，很短。像怕停太久，被楼道录成某一句。

你开门。她看窗台那件校服。你说忘了收。她没戳穿。

妈妈敲门。扣子扣对了。问：汤要不要热。赵宜说要。

两层便利贴。两个解。漏的那一个，妈妈也认。

她靠沙发：「停止键那道缝，很窄。爬很久。」

你问：疼吗。她说：疼比怕好。

你盖薄毯。握袖口。空半拍时，她就回来。

像按停止。停止不是结束。是留缝。

缝窄。窄够了。

天亮了。小的路，开始变成白天也要走的事。
小的路回家。她抓袖口。偶尔漏半拍。你说八，她笑。

她说完整你就薄。你按了停止，没听完整盘。

单元楼声控灯准时。七级停，你说八。额头抵肩，很短。

家里。她看窗台校服。你撒谎忘了收。

妈妈来。扣子对了。汤要热。两层便利贴。漏的那一个，妈妈认。

她靠沙发：缝窄。爬很久。疼比怕好。

你盖毯。握袖口。空半拍时她回来。

手机恢复。别走大路。这次走了小的。

天亮了。小的路变成白天也要走的事。

黎明时，她梦里说一句很轻的欢迎光临，随即自己皱眉，咽回去。你把胸前那颗糖挪到她枕头边。她没醒。呼吸完整。完整里偶尔空半拍。你握袖口。像守夜。守的不是病，是漏句别漏回去。
她一边走一边把漏掉的半个音节试着补全，补成各种可能：我选回家；我选往前；我选你。她笑：都不是。漏掉的那个，其实是怕。疼就抓袖口。袖口在，漏句就还是人。单元楼道灯准时。八。沙发她睡不整齐。新便利贴压旧便利贴。两层橙色。两层都写着两个解。黎明敲门妈妈。扣子对了。汤要热。你守夜。握袖口。

沙发上，她睡不整齐。呼吸完整，里偶尔空半拍。你握袖口。像守夜。守漏句别漏回去。妈妈热汤。她哑声说要。两层便利贴。漏的那一个，也认。天亮了。小的路开始变成白天也要走。

黎明前，她梦里说欢迎光临，又皱眉咽回去。你把糖放她枕头边。妈妈热汤。她哑声要。你说两个解，漏的那一个你也认。妈妈点头。她靠沙发：「停止键缝窄。爬很久。」你问：「还疼吗？」「疼。」「比怕好。」你握袖口。空半拍时，她就回来。天亮了。

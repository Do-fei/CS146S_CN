# 第二十三章　八个早晨

卷四不是岔路的攻略。是城在十一点之后，还亮着的别的窗口。八个早晨，八个并排，没有官方正确答案。

**静音的早晨**

南横街早市还没开，你已在教室。第三排靠窗，她举手答对了，你在过道边，像转班生。下课她借橡皮，角沾蓝笔，是她的习惯。你问：你记得我吗。她歪头：记得啊。你数学不好。只有你知道，夹层里还有一个她，清楚，薄，摸不到。你两个都守，守到西单耳机灯灭一次，像夹层平安。老歌里忽然喊你小名。你不倒带。班级合影里你的位置空着，第三排靠窗却坐着完整的她。你每天带两颗糖，一颗给自己，一颗放在扬声器墙下。墙不发声。你仍买豆浆，两杯，一杯放她桌角。她喝，说谢谢。像对普通同桌。只有你知道，夹层里还有一个她，摸不到。

**馆藏的早晨**

课桌糖少一颗。你补，又少。西单四楼耳机灯青绿。你不抬头。抬头，喇叭用你的嗓子。赵宜不在，也不在淡。她在保管中。状态比名字安全。你把静音筹码压数学卷上。卷下，省略号。音乐课，耳机喊小名。你摘耳机。不回头。回头会打开锁。你路过西单，从不抬头。抬头，欢迎光临会用你的声音。22:59，无号码短信：等待也是让句子还热。你不回。

**随河的早晨**

护城河冬天有冰，冰上有小孩滑，滑完请豆浆。现在冰没了，只剩鱼纹。鱼纹像学号，一闪又没。你不对水喊名字。喊了，雾会凝成她的名字，河就会涨。小海在别处，衣服干着，仍绕开倒影。你把豆浆倒栏外，敬岸。第三排靠窗空。你点名替她答：请假。不结案。22:59，桥边水里闪橙。你当风。你把糖纸叠船，放河。船稳。稳像沉。

**对调的早晨**

你在玻璃后。学号鱼侧面空，后来学会。她闭馆后来，不敲，只贴糖纸。糖纸越来越多，像窗。馆长把灯先对你亮。先亮是敬礼。你呼吸放慢，慢成灯。灯漂亮。灯没有回家的路。可糖纸闪，路就出现一下。你贴第三张糖纸。贴多了，像给未完成造一扇窗。窗不通风。通风，会把锁吹开。

**锁死的早晨**

雨停，路面仍像馆地板。须知第四条没印出来。很好。表示还没准备再选。玻璃里她写缩短的句子：明天见。明天见。明天见。你把掌心贴上去。温度反的。两岸都在。锁不是结束。是把结束按住。你读三遍明天见。读多了，像催。催是大路。你不催。你只贴掌。掌温反的，像两个解各在玻璃一侧。

**无站名的早晨**

空白票在数学书里，纸缘磨毛。你翻它，像翻一张没填的请假条。请假条上填：缓一天。缓一天，你还用得着。老周的车钟二十二点五十九，后座左边凹。凹像有人长期坐。坐的人不是你。你完整，她在车上。车上不报站。报站会把人写成站名。站名写进地图，就不好当说话的人。末班车经过天桥，车窗映她抱书包。你不拍窗。拍打像紧急制动。

**两站之间的早晨**

她半透明地上学。点名说还在两站之间。十一点以后的老师信。你每次坐车，经过那段空。空喊你。你回一声。不下车。下车，条件谈崩。她把撒的米饭捡回盒里：过期的。一起吃。橙色的车厢留在隧道里，像契约。契约不写名字。写名字，就只剩一站。你保留一声回应。回应不是应名。应名会把倒影交换。

**漏句的早晨**

你按过停止。她从缝里爬回。数学仍不会。袖口有褶。方程两个解，你们选漏的那个。疼就抓袖口。这是正本走的那条路。另八个早晨并在旁边，像同一张草稿纸的背面。她抓你袖口，说：甜的要沉。你嗯。发送成功。没有红色感叹号。消息发出去，像白天和夜里终于对上了口型。对不上口型的地方，留在卷四。留在并列的八个早晨。留在「我选——」后面那个没收完的音节。音节不大。够一个人爬回来。够两个人走小的路。

你读卷四，像读同一张草稿纸的背面。背面亮着八个窗口。窗口不必每个都打开。打开太多，会薄。薄了，就摸不到。你不想要那个。你想要袖口。想要漏句。想要两个解，各走各的，草稿纸上还能碰面。

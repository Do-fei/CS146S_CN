## 策略

- **50 章 × ~97,600 字** ≈ 488 万
- 每章在现有 ~6 万字基础上 **+3.7 万字** 独特场景（非循环）
- 不新增章节号，深化既有 50 章

## 每章必增内容

| 类型 | 要求 |
| --- | --- |
| 新惊悚单元 | 1 个完整事件，可查细节收尾 |
| 线索 | 推进 EXPANSION_3M 悬疑表之一 |
| 反转 | 半章内可验证 → 推翻一半 |
| 关系 | 二层甜度或家庭线 1 场 |
| 路线互证 | 每 3 章交叉引用小海/老周/阿青/档案线 |

- **00–08**：失踪前日常破防加深；23:17 伏笔多层

- **19–23**：卷四各结局再加 2 个独有场景/反转
- **24–28**：深线插章与正本互证
- **29–37**：档案+海洋馆+末班车各加「收费细节」

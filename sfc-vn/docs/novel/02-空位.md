# 第二章　空位

赵宜失踪的称呼，是第二天才在班里传开的。

不是警察宣布，是赵宜妈妈来学校那天。她坐在女儿的位子上，大衣没脱，头发扎得乱，眼睛肿。早自习还没开始，教室里已经坐了一半人。大家声音很轻，像怕惊动什么。

她看见你，笑了一下，又马上收回去，像做错事。

宜宜有没有跟你说要去哪儿？她问。

你摇头。

她把桌角那张「晚上豆浆，我请」揭起来，看了看，又贴回去。动作很轻，像怕把字蹭掉。

第二节课测验。课代表发卷子，到你这里多了一张，座位号写着赵宜。你做完自己的，又做她的——不是代写，是她昨天请假前说「这题我不会，你写完给我抄思路」。你写得很慢，怕老师看出来笔迹不对。交卷时两张叠在一起。老师拆开来，看了你一眼，没说话。

下课你路过公告栏。红榜贴的是上周数学小测，赵宜第三行，比你高两分。你站了十秒，把榜角抚平。有个男生在旁边说：她真不来了？你说不知道。他哦一声，走了。

班主任找你第二次，是在食堂。你端着餐盘找位，习惯性往靠窗走，走到一半停住，改坐过道边。饭吃到一半，筷子顿了一下——你以前不爱吃胡萝卜，她总是从对面伸筷子帮你夹走。今天盘子里胡萝卜还在。

班主任端碗坐你对面，没寒暄，直接问：她最近有没有异常？

你想了想：没有。

他说：作业、表情、手机？

你说：手机不知道。作业她数学老让我教。表情……她爱笑。

班主任点头。他吃饭很快，像赶时间。吃到一半又停住：她笔记里有没有奇怪的东西？倒带馆、海洋馆、夜班司机之类的？

你想起她撕下来塞在书包夹层的那页。上面写：阿青管声音，小海管水，老周管路。你当时问：作业提纲？她打你手背：别乱看。

你告诉班主任：提过名字。像故事。

他苦笑：那就不是胡话。有个学生很多年前也这么讲，后来回来了，只是再也不听音乐。

你脊背凉了一下：回来了？

班主任用纸巾擦嘴：人回来，习惯没全回来。他站起来：你沉。沉的人比较会回来。

你沉吗？你不确定。沉是什么？班主任没解释。你回座位，把赵宜的豆浆又推正一点。杯壁凝成水珠，顺着往下滚，滚到「晚上豆浆，我请」那个「请」字旁边。你拿纸巾擦，擦完又后悔——擦掉了，像擦掉她来过的证据。

午休时你路过小卖部，看见窗口还贴着值日表。打饭阿姨多舀半勺给你，说：你同桌那份我留着，她来了再热。你端餐盘，改坐过道边。靠窗那个位置空着，阳光打进来，打在空椅背上，像某种不合适的舞台光。

你吃两口，停。对面没人夹胡萝卜。你盯着胡萝卜，忽然想起她说过：胡萝卜对眼睛好，你不吃，以后看不清黑板，还得抄我笔记。你说抄就抄。她说：抄要付豆浆。你笑。现在胡萝卜还在盘子里。你挑出来，放餐盘边，像留空位。

下午最后一节是自习。你帮她补交英语听写本。本子里夹着她画的小人，小人举牌子：同桌加油。最后一页空白，她惯常留给你写评语。你写了句快点回来，又觉得太直，划掉，改成：作业我交了。划掉的那句还在，铅笔印浅，可看见。你合本子，像合上一扇没关严的门。

你只是把赵宜的豆浆放到桌角，放到它结皮，也没有扔。

你曾在发送失败后第一次把她的头像设成置顶，置顶上面还有班级群，群消息弹一次你心惊一次，心惊像23:17的回响。你把对话框翻到最后一条正常对话：数学最后一大题，我也不会，一起不会。然后红色感叹号。你写完了她的数学作业，字慢，慢得像等她检查步骤。人不对，作业对了也像错。

语文课，老师让同桌互改作文。你左边没人，右边是过道。你把她的本子拿过来，红笔划了两处，停住。第三处她写：同桌的背很直，像尺子。你划掉，改成：同桌今天没来。划完又觉得像告状，再划掉，留白。留白比告状更像你们。

下午体育课。分组缺人，体育老师念名单，念到赵宜停了一下，改念你的名字。你站在球场边，球弹过来砸脚背，疼，你没捡。同学帮你踢回来，说：发什么呆。你说：没。值日表还贴着赵宜的名字，黑板上写周三擦窗。你拿粉笔把「宜宜」两个字描深，粉笔灰沾指尖。后排有人笑，你当没听见。

放学后你去后勤处。失物招领玻璃后面挂着她的红围巾，角上还沾着粉笔。登记本签字栏空着。你记了号码，没领。怕领回去，她就真不回来了。

那天傍晚你又经过校门口。班主任站在门卫室旁边，肩湿了，没撑伞。第三排靠窗的灯还亮着。他看见你，问：你会不会出去找？你没否认。他点头：晚上小心。作业缓一天。

缓一天。你后来才听懂另一层意思：我希望你还用得着缓。

早读结束，你帮她把椅子推回去。椅背蹭过桌面，留下一道浅痕，和她平时推的位置差半指。前排女生回头问：她真不来了吗。你说不知道。女生哦一声，转回去跟同桌咬耳朵。你假装看书，一行字读了三遍。

你跟她最好。好是什么意思？好是数学卷子借来借去，是豆浆两杯总是一杯多出来，是她戳你手背说这题两个解，你选一个我选另一个。好不是告白。告白在这本书里太重，重得会把夜里的路压塌。好是同桌。同桌是作业、便当和袖口。

午饭你没去食堂。胃不饿。你在空教室里坐了一会儿，看第三排靠窗。窗外法桐树叶子被雨打得贴在一起，贴成一种深绿。赵宜说过，这种天适合睡午觉，不适合做数学。你说那你还做。她说：做是因为要跟你比分数。比赢了你请豆浆。你输多赢少。豆浆她请的次数反而更多。

下午化学实验，分组。名单上有赵宜的名字，老师划掉，改成随机。你那一组少了人，试管洗多一遍。洗试管时你想起她总洗不干净，被扣分，然后踩你脚，说同桌帮我洗。你洗。现在没人踩你脚。

放学铃响，你习惯性往左等两步，像等她追上来拍肩。没有人。校门口卖烤肠的阿姨问：今天一个人啊。你嗯一声，买了两根，一根揣兜里，烫，换到另一只手。以前总有一根是她的，她嫌烫，要等凉一点，说烫的豆浆可以，烫的烤肠不行，逻辑只有她能讲通。

第三天白天你没去上学。班主任在群里发作业，你没回。同学私聊问赵宜怎么样了，你回：不知道。对方发拥抱表情。你没回。

你独自回校拿练习册。走廊灯坏了一盏，另一盏闪。脚步声在空楼里很清楚。经过她的班，门半开，桌椅还是三天前的排列。你伸手推门，门轴响，像上课铃的余音。你站在门口，没进去。

练习册在抽屉里，扉页写着宜宜，两个字很小。你捏了捏，打算还给她——走到楼梯口才想起没有还的对象。你把练习册放进口袋，和钥匙分开放。

回家路上买了楼下小摊最后两个包子。习惯买两个，一个自己的，一个她的。你站在单元门口，多那个咬了两口，咽不下去，装进袋子里。

夜里你梦见还在上数学课。她拿粉笔敲你脑袋，说解错了。你醒来看手机，两点十七，没有新消息。窗外雨小了一点，又大了。你把梦里的步骤写在便利贴背面，字迹乱。

你对着天花板想：赵宜会不会也睡不着。如果她也睡不着，她会做什么？折糖纸？写笔记？还是站在窗边看雨，像你在做的这样？

你给她发：睡不着。发送失败。第四条了。你开始数。第五条、第六条，全是红色感叹号。像某种只有你能看见的游戏，没有通关界面。

你把梦里的步骤写在便利贴背面，背面还有空，空处你补一行：两个解，你选。选什么，选先喝豆浆的那个。写完了又觉得像替她选，替她选像作弊，你划掉，划掉像留半分空着。便利贴贴自己桌上，贴完像占座，占座不是结案。

第三天夜里你又路过校门口。班主任灯还亮，亮像一种还没撤回的许可。你站远处，数了三辆经过的出租车，第三辆尾灯红，红像发送失败。你没进去，进去像要汇报，汇报是大路。你转身走，走过打印店，打印店关门，门缝里透出一点潮味，潮味像湿鞋印还没干。

早上赵宜妈妈又发来语音。你犹豫很久，点开。这次没有哭，声音沙：同学，你要是……看见她……走小路。大路太亮，她怕。

你回：什么是大路？这次居然显示「已发送」。你心口一跳，立刻刷新——还是未读，然后变成发送失败。像系统跟你开了一个很短的玩笑。

你把手机扣在桌上。扣下去之前看见时间：10:43。离十一点还有一个多小时。你忽然意识到，她短信里写的不是「今晚十一点」，是「十一点后来」。后来可以是很久。也可以是现在。你抓起外套。

空位第三天，你开始替赵宜做小事。不是英雄，是同桌。帮她交英语听写，本子里小人举牌子：同桌加油。补交时老师看你一眼，没问。问会把故事写短。

值日表上你们名字并排。今天擦黑板本该她。你多擦一遍，粉笔灰落袖子上，白得像没洗干净的校服。你拍灰，灰又起，像某种不肯落地的名字。

体育课，两人三足。没人喊你配对。你绕场跑圈，跑第三圈，鞋带松，蹲下来系，系完抬头，看见靠窗那排同学在看台吃冰棍。你想起她说过：跑完步别立刻喝冰的，胃会疼。你当时说：你管真宽。她说：同桌不管谁管。

生物课观察叶脉，要两人合看一片。你把显微镜推到中间，独自调焦距。视野里叶脉分叉，像地图，像没有站名的路。你画下来，画完标注：赵宜请假。请假比失踪好写。

晚上你又去校门口。班主任灯还亮。你站远处，没进去。进去像要汇报。汇报是大路。你只想确认空位还在。还在，就表示没被人收走。收走空位，像结案。

那天夜里你其实醒过一次，23:17，手机震，你摸到了，屏幕亮，亮里是那两行字。你拇指滑开，想回，网还在，回不出去，像被什么掐断。掐断不是没网，是链断。你当时没有深想，深想是后来的事。你把手机扣回去，扣回去像把分钟也扣住，扣住了还是漏，漏进第二天红色感叹号。

窗台上晾着一件校服，不是你的。袖口有她常用的蓝笔渍。你伸手想收，手到一半停住，改成把窗关严一点。笔渍像某种还在路上的签名，签名干了，人可能还在某个会写字的地方。

第四天，课代表传新卷子。传到空位，代表停，把卷子放桌角，角卷起，像她折书签。你伸手，把卷子压平。压平，像替她呼吸。

你开始在空位桌肚里放东西。一颗糖，半块橡皮，一张没写完的便利贴：方程有两个解。写完了又划掉。划掉，因为两个解需要两个人选。一个人选，像作弊。

第五天，妈妈问：你同桌还没消息？你说：嗯。她说：那你吃饭。你说：嗯。她端汤，汤咸，你喝两口，想起赵宜妈妈说的：汤我没倒。咸说明还在等。你把碗推正，像推正一个空位。

空位第七天，你开始听见教室里的安静。安静不是没声音，是少了她弄出的那种：笔帽拔盖、糖纸窸窣、问「去不去小卖部」的尾音上扬。你习惯在铃响前回头，像等她拍肩。拍肩没来，空位在，像一张没写名字的卷子。

历史课，老师讲到某年某桥。你想起护城河天桥，白天丑，夜里橙。你低头，在课本边写：十一点后来。写完又划掉。划掉，因为发送失败。失败不是没收到。是收到却回不了。回不了，像单向的同桌。

你帮空位整理桌肚。桌肚里有半包纸巾，她惯常塞的；有折成三角的数学卷，三角是暗号；有蓝笔，笔帽咬痕很深。你把三角放回原处，像替她守着暗号。暗号就是我还活着。你当时笑。现在不笑。不笑，也不删。删了，像结案。

走廊里两个女生议论，说赵宜是不是跟家里吵架跑了。你路过，没接话。接话会把故事说短。说短了，大路就会来收。

你回教室，把她的透明伞又推深一点，推回桌肚。伞柄橘点对着你这边，像某种暗号。你认那个点。点还在，人就应该还在某个地方。

数学测验成绩下来。她仍第三行，比你高两分。你站公告栏前十秒，把榜角抚平。有个男生说：她真不来了？你说不知道。他走了。你站完十秒，第十一步才走。十秒是习惯。习惯不是等。是还给她一个位置。

空位第六天，地理课发新地图册。册子按座位号发，发到空位，课代表停住，把册子放桌角，像放一份还没来领的快递。你翻开自己的，里面夹着上次她借你的半张公交卡收据，时间23:17。你问这么晚，她当时说补作业。你信过，现在不确定。你把收据夹回书里，夹回像留疑点，疑点留着夜里才有路。

信息课，电脑登录名还挂着赵宜的拼音。你旁边的男生说：要不要帮她登出。你说不用。男生耸肩。屏幕保护程序是系统默认的星空，星点闪，闪像某种没有名字的站。你盯了三秒，关掉，没告诉老师。告诉老师像大路，大路会把看见的东西写成空白。

空位是一种声音。第三排靠窗空着，老师提问时少一个「赵宜」的应答。你应，或者不应，都会有人回头。回头里有一种探询：她真不来了吗。你说不知道。不知道不是敷衍。是诚实。

你在她的桌肚里找到一支笔。笔盖掉了，笔身蓝，是她常用的那支。你盖上，放回原处。像替她收拾一个还会回来的人的小习惯。

体育老师改念你的名字，你站在球场边，球砸脚背。疼。你没捡。同学踢回来。你说没发呆。你在想：如果她还在，她会捡，还会笑你反应慢。反应慢，她说，是因为数学想太多。

失物招领的红围巾，角上沾粉笔。你记号码，没领。领回去，像宣布她不会回来取。不宣布，就还能假装她只是请假。

你问过班主任：第三排靠窗的灯，为什么还亮。他说：有人看题看得久。你问：是赵宜的题吗。他摘眼镜：是空位的题。空位也有题。题是：人还会不会回来坐回来。你不懂。你懂的是灯亮着，你就还能假装她只是去小卖部。

保安夜里登记本空白那一格，你后来去问过。他说：想写来着，笔没水。你递笔。他摆手：写了，就得走大路。你问：不写呢。他说：不写，就得自己记。你记在心里。记：十一点前后，有人像她从后门出去，没撑伞，没应。

赵宜笔记里被橡皮擦过的半句，只剩「别」。别什么。别走大路？别喊名字？别答应倒影？你把「别」字抄在便利贴背面。背面还有23:17。两个疑点，像两道题。你一道也解不开。解不开，就先占座。占座，等夜里。

窄巷墙根有半张课表，第三排靠窗，名字被泥盖住。你不擦，擦了像替大路擦证据。泥留着像暗号，暗号就是我还活着。你当时笑，现在不笑。井盖上反出浅脸，你踩过去，脸笑了一下散了，下面极轻广播，报一个没有名字的站。你当没听见，听见就要应，应了站就会写你名。你不应，你走，走去灯还肯亮的地方。

修鞋铺老师傅指前面：胡同，就两个字。你谢了，他摆手：走你的。走你的像不要回报，回报是大路，大路写感谢信，写结案，你不写，你找，找走丢的人，找没说完的话。

窗台上收音机没拧紧，女声反复念：崇文，宣武，两个已经被拆进更大名字里的词。你想关窗，窗自己合上。玻璃上呵出字，很快没了：别走大路。你不确定谁呵的，不确定就留着。

空位第十天，你仍买两杯豆浆。小卖部阿姨问：同桌还没来啊。你说：嗯。她说：那杯我帮你热着。你谢了。谢完，像替赵宜谢。同桌的请，可以代收，不能代喝。你喝自己的。她的那杯，仍放桌角。结皮厚了。厚，像时间。

你帮她推椅子。椅背蹭桌面，浅痕。前排女生问：她真不来了吗。你说不知道。女生哦一声。你翻开书，草稿掉出来：你选。你选什么。选先喝豆浆的那个。你把草稿夹回书里。夹回，像夹住一个还会被问的问题。

傍晚校门口，烤肠阿姨问：今天一个人啊。你嗯。买两根。一根揣兜。烫，换手。以前总有一根是她的。现在两根都是你的。你咬自己的。另一个凉在兜里。凉，像某种还没决定的第三解。

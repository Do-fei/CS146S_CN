白天的北京（大路）

上班、点名、立案的那一层。老师留着第三排靠窗的灯，妈妈守着一锅汤，警察在大路上等。他们是真心在找人， 可这条路只会把事情写成纸面上的东西。走通了，赵宜就成了「请假三天」，你也回去当普通学生。

十一点，北京换皮肤

不解释为什么，城就是会换。夜里的钟停在二十二点五十九，秒针抖着不肯跳。跳到六十，人就被交还给点名册。 两层城的接缝在南城天桥：桥下积水里没有雨，是一个晴朗的下午，赵宜坐在栏杆上吃橘子。倒影会跟你说话。答应它，就要换人。

夜里的北京（小路）

赵宜不在某一个房间里等你救。她同时被三种东西保管着：一段声音，一个倒影，一趟车。 三条路都通向她，通向的她不一样。你选路，选的是见她的代价。每条路上只有一次真正的选择。

西单倒带馆

阿青管声音，耳廓里有磁带的驱动孔
收的是人来不及说出口、又不甘心死掉的那句话，做成磁带。赵宜留下一盘「未完成」， 磁带断在「我选」两个字上。
这里的账：放一次，句子短一点。放到最后，说话的人从照片上变淡。听的人也会变薄。
听完整盘 → 静音她被听完整，去了第四层。你在合影里让座。
交给阿青 → 馆藏两个人都停在未完成，像两杯没喝完的豆浆。
按下停止 → 漏句她带着漏句和疼，自己爬回人间。

北京海洋馆

小海管水，衣服干着，人总是潮的
玻璃里照出来的是另一座北京。岸上的北京催你快点，水里的北京让你停在二十二点五十九， 让你觉得被理解。赵宜喜欢被理解，所以她在水里站得稳。
这里的账：水箱一旦看清你，就会用你的名字给鱼起名。名字一多，岸上的人就轻。
蓝阀排空 → 随河水退回规矩，她跟着水去了护城河。
红阀对调 → 对调她上岸回白天，你留下当夜场展品。
白阀锁死 → 锁死今晚谁也不动，两岸维持原样。

无名地铁

老周管路，开夜班车，把钟按在 22:59
车往还没被叫出来的路开。没有站名，就不会被点名。窗外会有人用妈妈、老师、警察的脸朝你挥手。 脸是真的，那个站是大路伸过来的。
这里的账：车费是一枚两面都是赵宜的硬币。桥上放久的东西会变成站名。
坐到终点 → 无站名的早晨她留在路线里，你用硬币换回白天。
下一站下车 → 空白站白天完整还给你，她继续坐下去。这不算胆怯。
紧急制动 → 两站之间停在不属于任何人的地方谈条件。她半透明地回来， 你每次坐车都要经过一段会喊你名字的空。

夜里的规矩（就这几条）

  • 别走大路。大路安全，但会把人写成请假条。
  • 先别喊她的名字。一喊，水箱和广播就当成可以交换。
  • 别答应倒影。答应了就要换人。
  • 别把整盘磁带听完。说话的人完整，听的人薄。
  • 别在二十三点后数水母。数几只，馆外就灭几盏路灯。
  • 甜的要沉。沉住了，才不会飘进河，不会被报站冲走。

随身带的东西

  • 橘子糖是口令。对了，夜里的人给你让路。三颗，走一回少一颗。
  • 便当是证明。带着它，你还像一个会吃饭、会回家的人。
  • 温热的硬币是车费。店员找的那枚不用上车，留着记得自己会买东西。
  • 名字是全场最贵的东西。全城有称呼的只有四个人：赵宜、阿青、老周、小海。你只叫「你」。

这个游戏不做的事

  • 不做侦探戏。没有线索板，没有嫌疑人，没有那扇「对的门」。
  • 不做正确答案。九个结局并排放着，没有评分，没有隐藏结局。
  • 不解释十一点。没有上古契约，没有系统面板，城自己换皮肤。
  • 赵宜只说一句：选你最不怕后悔的。怕的那种，留给白天。
一句话说完：夜里的北京就是同一座城不肯写进请假条的那一层。你带着糖和便当下去， 用一次选择决定她怎么被留下、怎么回来，或者由你留下。

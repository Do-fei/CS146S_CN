能做什么

书在这台手机上。提问用你自己的 Key。

书房

导入 EPUB、PDF、图片或文本。加密的书加不进来。

拍摄

拍照或从相册选页，裁切后放进书架。

划选与搭子

划一段可以记下，或拿去问。引用能回到原处。

一纸与回煲

每本书一张一纸。回煲按条看。导出默认不含私人笔记。

回看

今天该回头看的划线，会出现在一纸页。

备份

导出 zip，换机可以恢复。也可以传到自己的网盘。

安装

用 Chrome 打开本页，点下载。这是试用 debug 包。

1. 点「下载 Android 安装包」。

2. 允许这个来源安装，打开文件。

3. 重装会清书房，先到「我的」导出备份。

安装前

  • Android 8 及以上。
  • 换成正式签名包需要先卸载，书房会一起清掉。
  • 较大的 PDF 按页识别。
  • Key 和网盘密码只存在本机，不进备份包。

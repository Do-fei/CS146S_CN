本机书房

EPUB、PDF、图片和文本会复制进私有目录。加密文件会被拒绝，不会尝试绕过。

纸书自炊

拍照或从相册选页，先裁切旋转，再做成摘录书。印刷识别在手机上完成。

划选与搭子

划一段可以记下你的话，或拿这段去问。引用能点回原文位置。

一纸与回煲

把书收成一张能发出去的纸。回煲按条审阅。出煲默认不含私人笔记。

文火回看

按本机日历日回看划线。不是闪卡，也没有间隔算法。

完整备份

导出 zip，含原书、划线、进度和扫描页。WebDAV 填你自己的盘，后写覆盖。

在手机上安装

用 Chrome 打开本页，点下载。装的是试用 debug 包，不是应用商店签名。

1. 点上方或底部的「下载 Android 安装包」。Chrome 会收下约 65MB 的 APK。

2. 允许这一个来源安装应用，打开文件即可。

3. 先导入随包说明书试读。换机或重装前，请先到「备份恢复」导出 zip。

请先知道

  • 需要 Android 8 或更新。尚未在 Pixel 7、OPPO 小折叠真机上关闭门禁。
  • 以后若换成正式签名包，需要先卸载。书房会一起清掉，先备份。
  • 超过 32MB 的 PDF 不整本抽文本层，可按页识别，不当原文。
  • 手写校对是打字改用户稿，不是数字墨水。库内检索是 n-gram，不是向量。
  • DeepSeek Key 与 WebDAV 密码只放本机密钥库，不进备份包。
